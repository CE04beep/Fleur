# Instruction pour OpenCode
## Mode de fonctionnement obligatoire
- **Travail par étapes :**Ne fais jamais tout le code d'un coup. Découpe chaque tache en sous-étapes simples.
- **Demande de vérification :**A la fin de chaque étape, arrete toi et demande validation avant de continuer
- **Quand tu reprends une tache, pars toujours du fichier le plus récent

## Style de code (HTML/CSS/JS)
- Ecris un code HTML propre, valide et bien indenté.
- Ajoute des commentaires clairs dans le code pour m'expliquer ce que tu fais
- Sépare bien le HTML, le CSS et le JavaScript si le projet grandit
